# Nítido Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS app that shares a screen or window to another Mac on the local network with crisp text, measured latency and drawing on top, built in four days as the Pairio prototype described in `docs/superpowers/specs/2026-10-07-nitido-design.md`.

**Architecture:** One Swift package with six targets. `NitidoCore` holds everything that is pure and testable (wire protocol, telemetry, bitrate policy, ink geometry, pairing). `NitidoCapture`, `NitidoCodec` and `NitidoLink` wrap ScreenCaptureKit, VideoToolbox and Network.framework behind small async interfaces. `NitidoUI` renders with Metal and SwiftUI. The `nitido` executable only wires modules together. A script assembles and signs `Nítido.app`.

**Tech Stack:** Swift 6.2 (strict concurrency), SwiftPM, SwiftUI + AppKit, ScreenCaptureKit, VideoToolbox, CoreMedia, Network.framework, CryptoKit, Metal/CoreImage, XCTest. No third-party dependencies.

## Global Constraints

- Deployment target macOS 15; `glassEffect` only inside `if #available(macOS 26, *)`, with `.ultraThinMaterial` fallback.
- Swift tools version 6.2, `swiftLanguageMode(.v6)` on every target; the package must build with zero warnings under strict concurrency.
- No third-party dependencies. Only Apple frameworks.
- Bundle id `ai.ronar.nitido`, app name `Nítido`, Bonjour type `_nitido._tcp`, log subsystem `ai.ronar.nitido`.
- Wire protocol exactly as in spec section 6: big-endian, header `u32 length · u8 type`, max payload 16 MiB.
- Colors: background `#08090c`, surface `#0e1015`, hairline `#2b2e38`, muted `#3a3e4a`, text `#f2f3f5`, gold `#c9a86a`, gold highlight `#d8ba7e`, cream `#f3e3ba`, success `#62c37e`, soft red `#e08f8f` (destructive confirmation only).
- Type: SF Pro for interface text, SF Mono for figures, Cormorant Garamond Italic for the wordmark only, Marcellus for small-caps labels. Fonts bundled under the OFL.
- Motion: entrances `cubic-bezier(0.23, 1, 0.32, 1)` under 250 ms from opacity 0 / scale 0.96; press feedback scale 0.97 over 120 ms; connect ring spring (duration 0.5, bounce 0.2) once per connection; list stagger 40 ms; ink fades 4 s after the last point over 600 ms; keyboard-triggered changes are instant; `accessibilityReduceMotion` removes scale and the ring.
- Never use the em dash character in any user-facing or repository text.
- Commit after every task with a conventional message; never add AI attribution to commits.
- Every failure is visible in the UI and logged with `os.Logger`; no `try?` that hides an error the user needs.

```swift
import Foundation

/// Big-endian byte writer. Everything on the wire goes through here.
public struct ByteWriter: Sendable {
    public private(set) var data = Data()
    public init() {}
    public mutating func u8(_ v: UInt8) { data.append(v) }
    public mutating func u16(_ v: UInt16) { data.append(UInt8(v >> 8)); data.append(UInt8(v & 0xff)) }
    public mutating func u32(_ v: UInt32) {
        for shift in stride(from: 24, through: 0, by: -8) { data.append(UInt8((v >> UInt32(shift)) & 0xff)) }
    }
    public mutating func u64(_ v: UInt64) {
        for shift in stride(from: 56, through: 0, by: -8) { data.append(UInt8((v >> UInt64(shift)) & 0xff)) }
    }
    public mutating func f32(_ v: Float) { u32(v.bitPattern) }
    public mutating func bytes(_ d: Data) { data.append(d) }
    /// UTF-8 with a one-byte length prefix; longer strings are cut to 255 bytes.
    public mutating func string8(_ s: String) {
        let d = Data(s.utf8.prefix(255))
        u8(UInt8(d.count)); data.append(d)
    }
}

public enum ByteError: Error, Equatable, Sendable { case truncated, malformed }

/// Big-endian byte reader over any Data (works on slices with non-zero start index).
public struct ByteReader {
    private let data: Data
    private var offset: Int
    public init(_ data: Data) { self.data = data; self.offset = data.startIndex }
    public var remaining: Int { data.endIndex - offset }
    public var isAtEnd: Bool { remaining == 0 }
    public mutating func u8() throws -> UInt8 {
        guard remaining >= 1 else { throw ByteError.truncated }
        let v = data[offset]; offset += 1; return v
    }
    public mutating func u16() throws -> UInt16 {
        let hi = try u8(); let lo = try u8()
        return (UInt16(hi) << 8) | UInt16(lo)
    }
    public mutating func u32() throws -> UInt32 {
        var v: UInt32 = 0
        for _ in 0..<4 { let b = try u8(); v = (v << 8) | UInt32(b) }
        return v
    }
    public mutating func u64() throws -> UInt64 {
        var v: UInt64 = 0
        for _ in 0..<8 { let b = try u8(); v = (v << 8) | UInt64(b) }
        return v
    }
    public mutating func f32() throws -> Float { Float(bitPattern: try u32()) }
    public mutating func bytes(_ n: Int) throws -> Data {
        guard n >= 0, remaining >= n else { throw ByteError.truncated }
        let d = data.subdata(in: offset..<(offset + n)); offset += n; return d
    }
    public mutating func rest() -> Data {
        let d = data.subdata(in: offset..<data.endIndex); offset = data.endIndex; return d
    }
    public mutating func string8() throws -> String {
        let n = Int(try u8())
        let d = try bytes(n)
        guard let s = String(data: d, encoding: .utf8) else { throw ByteError.malformed }
        return s
    }
}
```

```swift
import Foundation

public enum WireError: Error, Equatable, Sendable {
    case oversized(Int)
    case truncated
    case malformed(type: UInt8)
}

public enum Wire {
    public static let maxPayload = 16 * 1024 * 1024
    public static let headerSize = 5

    public static func encode(_ m: Message) -> Data {
        var w = ByteWriter()
        switch m {
        case .hello(let h):
            w.u16(h.protocolVersion); w.u8(h.role.rawValue); w.string8(h.name)
            w.u16(h.pixelWidth); w.u16(h.pixelHeight); w.f32(h.scale)
        case .videoConfig(let c):
            w.u8(c.codec.rawValue); w.u16(c.width); w.u16(c.height)
            w.u8(UInt8(min(c.parameterSets.count, 255)))
            for ps in c.parameterSets.prefix(255) { w.u16(UInt16(min(ps.count, 65535))); w.bytes(ps.prefix(65535)) }
        case .videoFrame(let f):
            w.u32(f.seq); w.u64(f.captureHostTimeNs); w.u8(f.isKey ? 1 : 0); w.bytes(f.data)
        case .stroke(let s):
            w.u32(s.strokeId); w.u8(s.phase.rawValue); w.u8(s.color.r); w.u8(s.color.g); w.u8(s.color.b)
            w.f32(s.baseWidth); w.u16(UInt16(min(s.points.count, 65535)))
            for p in s.points.prefix(65535) { w.f32(p.x); w.f32(p.y); w.f32(p.pressure); w.u32(p.tMs) }
        case .cursor(let c):
            w.f32(c.x); w.f32(c.y); w.u8(c.visible ? 1 : 0)
        case .ping(let id, let t):
            w.u32(id); w.u64(t)
        case .pong(let id, let o, let r):
            w.u32(id); w.u64(o); w.u64(r)
        case .keyframeRequest, .clear:
            break
        case .undo(let id):
            w.u32(id)
        case .bye(let reason):
            w.u8(reason)
        }
        var out = ByteWriter()
        out.u32(UInt32(w.data.count)); out.u8(m.typeCode); out.bytes(w.data)
        return out.data
    }

    /// Accumulates chunks from a byte stream and yields whole messages. Unknown types are skipped.
    public struct Decoder: Sendable {
        private var buffer = Data()
        public init() {}

        public mutating func feed(_ chunk: Data) throws -> [Message] {
            buffer.append(chunk)
            var out: [Message] = []
            while buffer.count >= Wire.headerSize {
                var r = ByteReader(buffer)
                let length = Int(try r.u32())
                let type = try r.u8()
                guard length <= Wire.maxPayload else { throw WireError.oversized(length) }
                let total = Wire.headerSize + length
                guard buffer.count >= total else { break }
                let payload = buffer.subdata(in: Wire.headerSize..<total)
                buffer = buffer.subdata(in: total..<buffer.count)
                if let m = try Wire.decodePayload(type: type, payload) { out.append(m) }
            }
            return out
        }
    }

    static func decodePayload(type: UInt8, _ payload: Data) throws -> Message? {
        var r = ByteReader(payload)
        do {
            switch type {
            case 1:
                let v = try r.u16()
                guard let role = Role(rawValue: try r.u8()) else { throw WireError.malformed(type: type) }
                let name = try r.string8(); let w = try r.u16(); let h = try r.u16(); let s = try r.f32()
                return .hello(Hello(protocolVersion: v, role: role, name: name, pixelWidth: w, pixelHeight: h, scale: s))
            case 2:
                guard let codec = Codec(rawValue: try r.u8()) else { throw WireError.malformed(type: type) }
                let w = try r.u16(); let h = try r.u16(); let n = Int(try r.u8())
                var sets: [Data] = []
                for _ in 0..<n { let len = Int(try r.u16()); sets.append(try r.bytes(len)) }
                return .videoConfig(VideoConfig(codec: codec, width: w, height: h, parameterSets: sets))
            case 3:
                let seq = try r.u32(); let t = try r.u64(); let key = try r.u8() == 1
                return .videoFrame(VideoFrame(seq: seq, captureHostTimeNs: t, isKey: key, data: r.rest()))
            case 4:
                let id = try r.u32()
                guard let phase = StrokePhase(rawValue: try r.u8()) else { throw WireError.malformed(type: type) }
                let color = RGB(r: try r.u8(), g: try r.u8(), b: try r.u8())
                let base = try r.f32(); let n = Int(try r.u16())
                var pts: [StrokePoint] = []; pts.reserveCapacity(n)
                for _ in 0..<n {
                    let x = try r.f32(); let y = try r.f32(); let p = try r.f32(); let t = try r.u32()
                    pts.append(StrokePoint(x: x, y: y, pressure: p, tMs: t))
                }
                return .stroke(StrokeMessage(strokeId: id, phase: phase, color: color, baseWidth: base, points: pts))
            case 5:
                let x = try r.f32(); let y = try r.f32(); let v = try r.u8() == 1
                return .cursor(Cursor(x: x, y: y, visible: v))
            case 6:
                let id = try r.u32(); let t = try r.u64()
                return .ping(id: id, tNs: t)
            case 7:
                let id = try r.u32(); let o = try r.u64(); let rp = try r.u64()
                return .pong(id: id, originalTNs: o, replyTNs: rp)
            case 8: return .keyframeRequest
            case 9: return .undo(strokeId: try r.u32())
            case 10: return .clear
            case 11: return .bye(reason: try r.u8())
            default: return nil
            }
        } catch ByteError.truncated {
            throw WireError.truncated
        } catch ByteError.malformed {
            throw WireError.malformed(type: type)
        }
    }
}
```

```swift
import Foundation

public struct Stats: Sendable, Equatable {
    public var count: Int, mean: Double, min: Double, max: Double, p50: Double, p95: Double
}

/// Time-bounded sample buffer. Times are seconds; samples must arrive in non-decreasing time order.
public struct RollingWindow: Sendable {
    public let seconds: Double
    private var times: [Double] = []
    private var values: [Double] = []

    public init(seconds: Double) { self.seconds = seconds }

    public mutating func add(_ value: Double, at t: Double) {
        times.append(t); values.append(value); prune(now: t)
    }

    public mutating func prune(now: Double) {
        let cutoff = now - seconds
        var drop = 0
        while drop < times.count, times[drop] < cutoff { drop += 1 }
        if drop > 0 { times.removeFirst(drop); values.removeFirst(drop) }
    }

    public func values(now: Double) -> [Double] {
        let cutoff = now - seconds
        return zip(times, values).filter { $0.0 >= cutoff }.map(\.1)
    }

    public func count(now: Double) -> Int { values(now: now).count }

    public func stats(now: Double) -> Stats? {
        let v = values(now: now).sorted()
        guard !v.isEmpty else { return nil }
        func rank(_ p: Double) -> Double { v[max(0, min(v.count - 1, Int((p * Double(v.count)).rounded(.up)) - 1))] }
        return Stats(count: v.count, mean: v.reduce(0, +) / Double(v.count), min: v[0], max: v[v.count - 1],
                     p50: rank(0.5), p95: rank(0.95))
    }
}

public struct Snapshot: Sendable, Equatable {
    public var captureFPS: Double
    public var displayFPS: Double
    public var latencyMs: Double?
    public var latencyP95Ms: Double?
    public var rttMs: Double?
    public var bitrateMbps: Double
    public var droppedLastSecond: Int
    /// Latency samples of the last two seconds, oldest first, for the sparkline.
    public var latencySeries: [Double]
    public static let empty = Snapshot(captureFPS: 0, displayFPS: 0, latencyMs: nil, latencyP95Ms: nil, rttMs: nil,
                                       bitrateMbps: 0, droppedLastSecond: 0, latencySeries: [])
}

public struct Telemetry: Sendable {
    private var captures = RollingWindow(seconds: 1)
    private var displays = RollingWindow(seconds: 1)
    private var latency = RollingWindow(seconds: 1)
    private var latencySeries = RollingWindow(seconds: 2)
    private var rtt = RollingWindow(seconds: 1)
    private var bytes = RollingWindow(seconds: 1)
    private var drops = RollingWindow(seconds: 1)

    public init(now: Double) {}

    public mutating func recordCapture(at t: Double) { captures.add(1, at: t) }
    public mutating func recordDisplay(at t: Double) { displays.add(1, at: t) }
    public mutating func recordLatency(ms: Double, at t: Double) { latency.add(ms, at: t); latencySeries.add(ms, at: t) }
    public mutating func recordRTT(ms: Double, at t: Double) { rtt.add(ms, at: t) }
    public mutating func recordBytes(_ n: Int, at t: Double) { bytes.add(Double(n), at: t) }
    public mutating func recordDrop(at t: Double) { drops.add(1, at: t) }

    public func snapshot(now: Double) -> Snapshot {
        let lat = latency.stats(now: now)
        let bits = bytes.values(now: now).reduce(0, +) * 8
        return Snapshot(captureFPS: Double(captures.count(now: now)),
                        displayFPS: Double(displays.count(now: now)),
                        latencyMs: lat?.p50, latencyP95Ms: lat?.p95,
                        rttMs: rtt.stats(now: now)?.p50,
                        bitrateMbps: bits / 1_000_000,
                        droppedLastSecond: drops.count(now: now),
                        latencySeries: latencySeries.values(now: now))
    }
}
```

```swift
import Foundation

/// Deterministic bitrate policy (spec section 8). Call `update` every 250 ms.
public struct BitrateController: Sendable {
    public let minimum: Int
    public let maximum: Int
    public private(set) var bitsPerSecond: Int

    private var rttHistory = RollingWindow(seconds: 10)
    private var lastChange: Double?

    public init(initial: Int, minimum: Int = 2_000_000, maximum: Int = 60_000_000) {
        self.minimum = minimum; self.maximum = maximum
        self.bitsPerSecond = Swift.max(minimum, Swift.min(maximum, initial))
    }

    /// 20 Mbps at 1080p, scaled by pixel count, clamped to the default bounds.
    public static func initialBitrate(width: Int, height: Int) -> Int {
        let bps = 20_000_000 * Double(width * height) / (1920 * 1080)
        return Swift.max(2_000_000, Swift.min(60_000_000, Int(bps)))
    }

    public mutating func update(rttMs: Double?, backlogBytes: Int, frameAgeMs: Double?, fps: Double, now: Double) -> Int {
        if let rttMs { rttHistory.add(rttMs, at: now) }
        let baseline = rttHistory.stats(now: now)?.min
        let frameBytes = Double(bitsPerSecond) / 8 / Swift.max(fps, 1)

        let rttTooHigh = rttMs.flatMap { r in baseline.map { r > $0 + 40 } } ?? false
        let rttHealthy = rttMs.flatMap { r in baseline.map { r <= $0 + 15 } } ?? true
        let stale = (frameAgeMs ?? 0) > 150
        let congested = Double(backlogBytes) > 2 * frameBytes || rttTooHigh || stale
        let healthy = Double(backlogBytes) < frameBytes && rttHealthy && !stale

        if let last = lastChange, now - last < 2 { return bitsPerSecond }
        if congested {
            bitsPerSecond = Swift.max(minimum, bitsPerSecond * 3 / 4); lastChange = now
        } else if healthy {
            bitsPerSecond = Swift.min(maximum, bitsPerSecond * 11 / 10); lastChange = now
        }
        return bitsPerSecond
    }
}
```

```swift
import Foundation

public struct Stroke: Sendable, Equatable, Identifiable {
    public let id: UInt32
    public var color: RGB
    public var baseWidth: Float
    public var points: [StrokePoint]
    public var isRemote: Bool
    public var startedAt: Double
    public var endedAt: Double?
}

public enum InkGeometry {
    /// Centripetal Catmull-Rom through the points: `segments` interpolated points per span, endpoints kept exactly.
    public static func smooth(_ pts: [StrokePoint], segments: Int = 6) -> [SIMD2<Float>] {
        let p = pts.map { SIMD2($0.x, $0.y) }
        guard p.count > 1 else { return p }
        var out: [SIMD2<Float>] = [p[0]]
        for i in 0..<(p.count - 1) {
            let p0 = i == 0 ? p[0] : p[i - 1]
            let p1 = p[i], p2 = p[i + 1]
            let p3 = i + 2 < p.count ? p[i + 2] : p[i + 1]
            for s in 1...segments {
                let t = Float(s) / Float(segments)
                let t2 = t * t, t3 = t2 * t
                let v = 0.5 * ((2 * p1) + (-p0 + p2) * t + (2 * p0 - 5 * p1 + 4 * p2 - p3) * t2 + (-p0 + 3 * p1 - 3 * p2 + p3) * t3)
                out.append(s == segments ? p2 : v)
            }
        }
        return out
    }

    /// Fast strokes are thin: width = base * clamp(1.2 - speed * 400, 0.35, 1.2). Speed is picture units per ms.
    public static func width(base: Float, speedPerMs: Float) -> Float {
        base * min(1.2, max(0.35, 1.2 - speedPerMs * 400))
    }

    public static func speed(from a: StrokePoint, to b: StrokePoint) -> Float {
        let d = ((b.x - a.x) * (b.x - a.x) + (b.y - a.y) * (b.y - a.y)).squareRoot()
        return d / Float(max(1, Int(b.tMs) - Int(a.tMs)))
    }
}

public struct InkDocument: Sendable, Equatable {
    public private(set) var strokes: [Stroke] = []
    public var fadeAfter: Double = 4
    public var fadeDuration: Double = 0.6
    private var counter: UInt32 = 0

    public init() {}

    /// Share side allocates even ids, view side odd ids, so the two peers never collide.
    public mutating func allocateId(role: Role) -> UInt32 {
        counter += 1
        return counter * 2 + (role == .share ? 0 : 1)
    }

    public mutating func apply(_ m: StrokeMessage, isRemote: Bool, now: Double) {
        switch m.phase {
        case .begin: begin(id: m.strokeId, color: m.color, baseWidth: m.baseWidth, points: m.points, isRemote: isRemote, now: now)
        case .append: append(id: m.strokeId, points: m.points)
        case .end: end(id: m.strokeId, now: now)
        }
    }

    public mutating func begin(id: UInt32, color: RGB, baseWidth: Float, points: [StrokePoint], isRemote: Bool, now: Double) {
        strokes.removeAll { $0.id == id }
        strokes.append(Stroke(id: id, color: color, baseWidth: baseWidth, points: points, isRemote: isRemote, startedAt: now, endedAt: nil))
    }

    public mutating func append(id: UInt32, points: [StrokePoint]) {
        guard let i = strokes.firstIndex(where: { $0.id == id }) else { return }
        strokes[i].points.append(contentsOf: points)
    }

    public mutating func end(id: UInt32, now: Double) {
        guard let i = strokes.firstIndex(where: { $0.id == id }) else { return }
        strokes[i].endedAt = now
    }

    @discardableResult
    public mutating func undoLastLocal() -> UInt32? {
        guard let i = strokes.lastIndex(where: { !$0.isRemote }) else { return nil }
        return strokes.remove(at: i).id
    }

    public mutating func remove(id: UInt32) { strokes.removeAll { $0.id == id } }
    public mutating func clear() { strokes.removeAll() }

    /// 1 while drawing and for `fadeAfter` seconds after the end, then linear to 0 over `fadeDuration`.
    public func opacity(of s: Stroke, now: Double) -> Float {
        guard let end = s.endedAt else { return 1 }
        let t = now - end - fadeAfter
        if t <= 0 { return 1 }
        return Float(max(0, 1 - t / fadeDuration))
    }

    public mutating func prune(now: Double) {
        strokes.removeAll { opacity(of: $0, now: now) <= 0 }
    }
}
```

```swift
    case failed(String)

/// Wraps the system content picker and an SCStream. One session, one stream at a time.
@MainActor
public final class CaptureSession: NSObject {
    public let frames: AsyncStream<CapturedFrame>
    public let events: AsyncStream<CaptureEvent>
    private let frameOut: AsyncStream<CapturedFrame>.Continuation
    private let eventOut: AsyncStream<CaptureEvent>.Continuation
    private let output: FrameOutput
    private let queue = DispatchQueue(label: "ai.ronar.nitido.capture", qos: .userInteractive)
    private var stream: SCStream?

    public override init() {
        let (f, fc) = AsyncStream<CapturedFrame>.makeStream(bufferingPolicy: .bufferingNewest(1))
        let (e, ec) = AsyncStream<CaptureEvent>.makeStream(bufferingPolicy: .bufferingNewest(8))
        frames = f; frameOut = fc; events = e; eventOut = ec
        output = FrameOutput(continuation: fc)
        super.init()
    }

    /// Shows the system picker. Results arrive through `events` and then `frames`.
    public func presentPicker(excludingWindowIDs: [CGWindowID]) {
        let picker = SCContentSharingPicker.shared
        var config = SCContentSharingPickerConfiguration()
        config.allowedPickerModes = [.singleWindow, .singleDisplay]
        config.excludedWindowIDs = excludingWindowIDs.map { Int($0) }
        config.allowsChangingSelectedContent = true
        picker.defaultConfiguration = config
        picker.add(self)
        picker.isActive = true
        picker.present()
    }

    public func stop() async {
        SCContentSharingPicker.shared.isActive = false
        SCContentSharingPicker.shared.remove(self)
        guard let stream else { return }
        self.stream = nil
        do { try await stream.stopCapture() } catch { log.error("stopCapture: \(error.localizedDescription)") }
        eventOut.yield(.stopped)
    }

    private func start(with filter: SCContentFilter) async {
        let scale = CGFloat(filter.pointPixelScale)
        let rect = filter.contentRect
        let config = SCStreamConfiguration()
        config.width = Int((rect.width * scale).rounded())
        config.height = Int((rect.height * scale).rounded())
        config.minimumFrameInterval = CMTime(value: 1, timescale: 60)
        config.pixelFormat = kCVPixelFormatType_32BGRA
        config.colorSpaceName = CGColorSpace.sRGB
        config.showsCursor = true
        config.queueDepth = 3
        config.captureResolution = .best

        if let stream {
            do {
                try await stream.updateContentFilter(filter)
                try await stream.updateConfiguration(config)
                eventOut.yield(.started(pixelWidth: config.width, pixelHeight: config.height, scale: scale))
            } catch { eventOut.yield(.failed(error.localizedDescription)) }
            return
        }
        let stream = SCStream(filter: filter, configuration: config, delegate: self)
        do {
            try stream.addStreamOutput(output, type: .screen, sampleHandlerQueue: queue)
            try await stream.startCapture()
            self.stream = stream
            eventOut.yield(.started(pixelWidth: config.width, pixelHeight: config.height, scale: scale))
        } catch {
            log.error("startCapture: \(error.localizedDescription)")
            eventOut.yield(.failed(error.localizedDescription))
        }
    }
}

extension CaptureSession: SCContentSharingPickerObserver {
    nonisolated public func contentSharingPicker(_ picker: SCContentSharingPicker, didUpdateWith filter: SCContentFilter, for stream: SCStream?) {
        Task { @MainActor in await self.start(with: filter) }
    }
    nonisolated public func contentSharingPicker(_ picker: SCContentSharingPicker, didCancelFor stream: SCStream?) {
        Task { @MainActor in self.eventOut.yield(.cancelled) }
    }
    nonisolated public func contentSharingPickerStartDidFailWithError(_ error: any Error) {
        Task { @MainActor in self.eventOut.yield(.failed(error.localizedDescription)) }
    }
}

extension CaptureSession: SCStreamDelegate {
    nonisolated public func stream(_ stream: SCStream, didStopWithError error: any Error) {
        Task { @MainActor in
            self.stream = nil
            self.eventOut.yield(.failed(error.localizedDescription))
        }
    }
}

/// Receives sample buffers on the capture queue and yields only complete frames.
private final class FrameOutput: NSObject, SCStreamOutput, @unchecked Sendable {
    private let continuation: AsyncStream<CapturedFrame>.Continuation
    init(continuation: AsyncStream<CapturedFrame>.Continuation) { self.continuation = continuation }

    func stream(_ stream: SCStream, didOutputSampleBuffer sampleBuffer: CMSampleBuffer, of type: SCStreamOutputType) {
        guard type == .screen, sampleBuffer.isValid,
              let attachments = CMSampleBufferGetSampleAttachmentsArray(sampleBuffer, createIfNecessary: false) as? [[SCStreamFrameInfo: Any]],
              let info = attachments.first,
              let statusRaw = info[.status] as? Int, let status = SCFrameStatus(rawValue: statusRaw), status == .complete,
              let pixelBuffer = CMSampleBufferGetImageBuffer(sampleBuffer) else { return }
        let rect = (info[.contentRect] as? NSDictionary).flatMap { CGRect(dictionaryRepresentation: $0) } ?? .zero
        let scale = (info[.scaleFactor] as? CGFloat) ?? 1
        let seconds = (info[.displayTime] as? Double) ?? CACurrentMediaTime()
        continuation.yield(CapturedFrame(pixelBuffer: pixelBuffer, captureHostTimeNs: UInt64(seconds * 1e9), contentRect: rect, scale: scale))
    }
}
```

```swift
              let drawable = metalLayer.nextDrawable(),

            lanczos.setValue(image, forKey: kCIInputImageKey)
            lanczos.setValue(fit, forKey: kCIInputScaleKey)
            lanczos.setValue(1.0, forKey: kCIInputAspectRatioKey)
            image = lanczos.outputImage ?? image
        }
        let shown = image.extent.size
        image = image.transformed(by: CGAffineTransform(translationX: ((target.width - shown.width) / 2).rounded(),
                                                         y: ((target.height - shown.height) / 2).rounded()))
        let bounds = CGRect(origin: .zero, size: target)
        let background = CIImage(color: CIColor(red: 8 / 255, green: 9 / 255, blue: 12 / 255)).cropped(to: bounds)
        let destination = CIRenderDestination(mtlTexture: drawable.texture, commandBuffer: command)
        destination.colorSpace = colorSpace
        do {
            try ciContext.startTask(toRender: image.composited(over: background), from: bounds, to: destination, at: .zero)
        } catch {
            log.error("render: \(error.localizedDescription)")
            return
        }
        let callback = onPresented
        drawable.addPresentedHandler { presented in
            let at = presented.presentedTime
            Task { @MainActor in callback?(captureHostTimeNs, at) }
        }
        command.present(drawable)
        command.commit()
    }
}
```

```swift
            guard let self else { return }
            telemetry.recordDisplay(at: presentedAt)
            telemetry.recordLatency(ms: (presentedAt - Double(captureNs) / 1e9) * 1000, at: presentedAt)
        }
    }

    public var resolutionLabel: String {
        pixelSize == .zero ? "·" : "\(Int(pixelSize.width))×\(Int(pixelSize.height)) @\(Int(scale))x"
    }

    public func start(excludingWindowIDs: [CGWindowID]) {
        if case .picking = state { return }
        if case .capturing = state { return }
        state = .picking
        tasks.forEach { $0.cancel() }
        tasks = [
            Task { [weak self] in
                guard let self else { return }
                for await event in capture.events { handle(event) }
            },
            Task { [weak self] in
                guard let self else { return }
                for await frame in capture.frames {
                    telemetry.recordCapture(at: Double(frame.captureHostTimeNs) / 1e9)
                    sink.push(frame.pixelBuffer, captureHostTimeNs: frame.captureHostTimeNs)
                }
            },
            Task { [weak self] in
                while !Task.isCancelled {
                    try? await Task.sleep(for: .milliseconds(250))
                    guard let self else { return }
                    snapshot = telemetry.snapshot(now: CACurrentMediaTime())
                }
            },
        ]
        capture.presentPicker(excludingWindowIDs: excludingWindowIDs)
    }

    private func handle(_ event: CaptureEvent) {
        switch event {
        case .started(let w, let h, let s):
            pixelSize = CGSize(width: w, height: h); scale = s; state = .capturing
        case .cancelled:
            state = .idle
        case .stopped:
            state = .idle
        case .failed(let message):
            state = .failed(message)
        }
    }

    public func stop() async {
        tasks.forEach { $0.cancel() }
        tasks = []
        await capture.stop()
        state = .idle
    }
}
```

```swift
    private let lock = NSLock()

    var value: T { lock.lock(); defer { lock.unlock() }; return inner }
}
```

```swift
import Foundation
import VideoToolbox
import CoreMedia
import CoreVideo
import NitidoCore
import os

private let log = Logger(subsystem: "ai.ronar.nitido", category: "codec")

public enum CodecError: Error, Equatable {
    case sessionCreate(OSStatus)
    case encode(OSStatus)
    case decode(OSStatus)
    case formatDescription(OSStatus)
}

public struct EncodedFrame: Sendable {
    public let seq: UInt32
    public let captureHostTimeNs: UInt64
    public let isKey: Bool
    /// NAL units with 4-byte big-endian length prefixes, exactly as VideoToolbox emits them.
    public let data: Data
    /// VPS/SPS/PPS (HEVC) or SPS/PPS (H.264); present on keyframes only.
    public let parameterSets: [Data]
    public let codec: Codec
    public let width: Int
    public let height: Int

    public var videoConfig: VideoConfig? {
        parameterSets.isEmpty ? nil : VideoConfig(codec: codec, width: UInt16(width), height: UInt16(height), parameterSets: parameterSets)
    }
    public var videoFrame: VideoFrame { VideoFrame(seq: seq, captureHostTimeNs: captureHostTimeNs, isKey: isKey, data: data) }
}

/// Realtime hardware encoder. Thread-safe; `onFrame` is called on a VideoToolbox queue.
public final class VideoEncoder: @unchecked Sendable {
    public let codec: Codec
    public let width: Int
    public let height: Int
    public var onFrame: (@Sendable (EncodedFrame) -> Void)?

    private var session: VTCompressionSession?
    private let lock = NSLock()
    private var seq: UInt32 = 0
    private var forceKey = true
    private var inFlight = 0

    public init(width: Int, height: Int, preferred: Codec = .hevc, bitsPerSecond: Int) throws {
        self.width = width; self.height = height
        let spec = [kVTVideoEncoderSpecification_RequireHardwareAcceleratedVideoEncoder: true] as CFDictionary
        func create(_ type: CMVideoCodecType) -> (OSStatus, VTCompressionSession?) {
            var s: VTCompressionSession?
            let st = VTCompressionSessionCreate(allocator: nil, width: Int32(width), height: Int32(height), codecType: type,
                                                encoderSpecification: spec, imageBufferAttributes: nil, compressedDataAllocator: nil,
                                                outputCallback: nil, refcon: nil, compressionSessionOut: &s)
            return (st, s)
        }
        var (status, created) = create(preferred == .hevc ? kCMVideoCodecType_HEVC : kCMVideoCodecType_H264)
        var chosen = preferred
        if status != noErr, preferred == .hevc {
            log.warning("no hardware HEVC encoder (\(status)), falling back to H.264")
            (status, created) = create(kCMVideoCodecType_H264); chosen = .h264
        }
        guard status == noErr, let s = created else { throw CodecError.sessionCreate(status) }
        codec = chosen
        session = s
        VTSessionSetProperty(s, key: kVTCompressionPropertyKey_RealTime, value: kCFBooleanTrue)
        VTSessionSetProperty(s, key: kVTCompressionPropertyKey_AllowFrameReordering, value: kCFBooleanFalse)
        VTSessionSetProperty(s, key: kVTCompressionPropertyKey_ProfileLevel,
                             value: chosen == .hevc ? kVTProfileLevel_HEVC_Main_AutoLevel : kVTProfileLevel_H264_High_AutoLevel)
        VTSessionSetProperty(s, key: kVTCompressionPropertyKey_MaxKeyFrameInterval, value: 120 as CFNumber)
        VTSessionSetProperty(s, key: kVTCompressionPropertyKey_ExpectedFrameRate, value: 60 as CFNumber)
        VTSessionSetProperty(s, key: kVTCompressionPropertyKey_PrioritizeEncodingSpeedOverQuality, value: kCFBooleanFalse)
        setBitrate(bitsPerSecond)
        VTCompressionSessionPrepareToEncodeFrames(s)
    }

    public func setBitrate(_ bitsPerSecond: Int) {
        guard let session else { return }
        VTSessionSetProperty(session, key: kVTCompressionPropertyKey_AverageBitRate, value: bitsPerSecond as CFNumber)
        let limits = [bitsPerSecond * 3 / 2 / 8, 1] as CFArray   // bytes per one-second window
        VTSessionSetProperty(session, key: kVTCompressionPropertyKey_DataRateLimits, value: limits)
    }

    public func requestKeyframe() { lock.lock(); forceKey = true; lock.unlock() }

    /// Returns false when the frame was dropped because two frames are already being encoded.
    @discardableResult
    public func encode(_ pixelBuffer: CVPixelBuffer, captureHostTimeNs: UInt64) -> Bool {
        guard let session else { return false }
        lock.lock()
        guard inFlight < 2 else { lock.unlock(); return false }
        inFlight += 1
        let key = forceKey; forceKey = false
        let n = seq; seq &+= 1
        lock.unlock()

        let pts = CMTime(value: CMTimeValue(captureHostTimeNs / 1000), timescale: 1_000_000)
        let props: CFDictionary? = key ? [kVTEncodeFrameOptionKey_ForceKeyFrame: true] as CFDictionary : nil
        let status = VTCompressionSessionEncodeFrame(session, imageBuffer: pixelBuffer, presentationTimeStamp: pts, duration: .invalid,
                                                     frameProperties: props, infoFlagsOut: nil) { [weak self] status, _, sample in
            guard let self else { return }
            self.lock.lock(); self.inFlight -= 1; self.lock.unlock()
            guard status == noErr, let sample else { log.error("encode callback: \(status)"); return }
            self.emit(sample, seq: n, captureHostTimeNs: captureHostTimeNs)
        }
        if status != noErr {
            lock.lock(); inFlight -= 1; lock.unlock()
            log.error("encode: \(status)")
            return false
        }
        return true
    }

    private func emit(_ sample: CMSampleBuffer, seq: UInt32, captureHostTimeNs: UInt64) {
        let attachments = CMSampleBufferGetSampleAttachmentsArray(sample, createIfNecessary: false) as? [[String: Any]]
        let notSync = attachments?.first?[kCMSampleAttachmentKey_NotSync as String] as? Bool ?? false
        let isKey = !notSync
        var sets: [Data] = []
        if isKey, let fd = CMSampleBufferGetFormatDescription(sample) { sets = Self.parameterSets(from: fd, codec: codec) }
        guard let block = CMSampleBufferGetDataBuffer(sample) else { return }
        let length = CMBlockBufferGetDataLength(block)
        var data = Data(count: length)
        let status = data.withUnsafeMutableBytes { raw -> OSStatus in
            CMBlockBufferCopyDataBytes(block, atOffset: 0, dataLength: length, destination: raw.baseAddress!)
        }
        guard status == noErr else { log.error("copy bytes: \(status)"); return }
        onFrame?(EncodedFrame(seq: seq, captureHostTimeNs: captureHostTimeNs, isKey: isKey, data: data,
                              parameterSets: sets, codec: codec, width: width, height: height))
    }

    static func parameterSets(from fd: CMFormatDescription, codec: Codec) -> [Data] {
        var count = 0
        var sets: [Data] = []
        if codec == .hevc {
            CMVideoFormatDescriptionGetHEVCParameterSetAtIndex(fd, parameterSetIndex: 0, parameterSetPointerOut: nil, parameterSetSizeOut: nil, parameterSetCountOut: &count, nalUnitHeaderLengthOut: nil)
            for i in 0..<count {
                var ptr: UnsafePointer<UInt8>? = nil; var size = 0
                CMVideoFormatDescriptionGetHEVCParameterSetAtIndex(fd, parameterSetIndex: i, parameterSetPointerOut: &ptr, parameterSetSizeOut: &size, parameterSetCountOut: nil, nalUnitHeaderLengthOut: nil)
                if let ptr { sets.append(Data(bytes: ptr, count: size)) }
            }
        } else {
            CMVideoFormatDescriptionGetH264ParameterSetAtIndex(fd, parameterSetIndex: 0, parameterSetPointerOut: nil, parameterSetSizeOut: nil, parameterSetCountOut: &count, nalUnitHeaderLengthOut: nil)
            for i in 0..<count {
                var ptr: UnsafePointer<UInt8>? = nil; var size = 0
                CMVideoFormatDescriptionGetH264ParameterSetAtIndex(fd, parameterSetIndex: i, parameterSetPointerOut: &ptr, parameterSetSizeOut: &size, parameterSetCountOut: nil, nalUnitHeaderLengthOut: nil)
                if let ptr { sets.append(Data(bytes: ptr, count: size)) }
            }
        }
        return sets
    }

    public func invalidate() {
        guard let session else { return }
        VTCompressionSessionCompleteFrames(session, untilPresentationTimeStamp: .invalid)
        VTCompressionSessionInvalidate(session)
        self.session = nil
    }

    deinit { invalidate() }
}
```

```swift
            sizes.withUnsafeBufferPointer { szs in
                config.codec == .hevc

            }

        guard status == noErr, let fd else { throw CodecError.formatDescription(status) }
        format = fd
        let attrs = [kCVPixelBufferPixelFormatTypeKey: kCVPixelFormatType_32BGRA,
                     kCVPixelBufferMetalCompatibilityKey: true] as CFDictionary

        let st = VTDecompressionSessionCreate(allocator: nil, formatDescription: fd, decoderSpecification: nil,
                                              imageBufferAttributes: attrs, outputCallback: nil, decompressionSessionOut: &s)
        guard st == noErr, let s else { throw CodecError.sessionCreate(st) }
        VTSessionSetProperty(s, key: kVTDecompressionPropertyKey_RealTime, value: kCFBooleanTrue)
        session = s
    }

    /// Synchronous: `onFrame` fires before this returns. Throws on malformed data.
    public func decode(_ frame: VideoFrame) throws {
        guard let session else { return }
        let data = frame.data
        var block: CMBlockBuffer?
        var status = CMBlockBufferCreateWithMemoryBlock(allocator: nil, memoryBlock: nil, blockLength: data.count, blockAllocator: nil,
                                                        customBlockSource: nil, offsetToData: 0, dataLength: data.count, flags: 0, blockBufferOut: &block)
        guard status == noErr, let block else { throw CodecError.decode(status) }
        status = data.withUnsafeBytes { raw in
            CMBlockBufferReplaceDataBytes(with: raw.baseAddress!, blockBuffer: block, offsetIntoDestination: 0, dataLength: data.count)
        }
        guard status == noErr else { throw CodecError.decode(status) }
        var timing = CMSampleTimingInfo(duration: .invalid,
                                        presentationTimeStamp: CMTime(value: CMTimeValue(frame.captureHostTimeNs / 1000), timescale: 1_000_000),
                                        decodeTimeStamp: .invalid)
        var size = data.count
        var sample: CMSampleBuffer?
        status = CMSampleBufferCreateReady(allocator: nil, dataBuffer: block, formatDescription: format, sampleCount: 1,
                                           sampleTimingEntryCount: 1, sampleTimingArray: &timing, sampleSizeEntryCount: 1,
                                           sampleSizeArray: &size, sampleBufferOut: &sample)
        guard status == noErr, let sample else { throw CodecError.decode(status) }
        let seq = frame.seq, t = frame.captureHostTimeNs
        var callbackStatus: OSStatus = noErr
        status = VTDecompressionSessionDecodeFrame(session, sampleBuffer: sample, flags: [], infoFlagsOut: nil) { [weak self] st, _, image, _, _ in
            callbackStatus = st
            guard st == noErr, let image, let self else { return }
            self.onFrame?(DecodedFrame(pixelBuffer: image, captureHostTimeNs: t, seq: seq))
        }
        guard status == noErr else { throw CodecError.decode(status) }
        guard callbackStatus == noErr else { throw CodecError.decode(callbackStatus) }
    }
```

```swift
/// Owns the ink document, allocates ids, and keeps the canvas in sync. One per window.
@MainActor
public final class InkController {
    public private(set) var document = InkDocument()
    public let role: Role
    public var onOutgoing: ((Message) -> Void)?
    weak var canvas: InkCanvasView?

    public init(role: Role) { self.role = role }

    // Local input (called by the canvas)
    func beginLocal(_ p: StrokePoint) -> UInt32 {
        let id = document.allocateId(role: role)
        let m = StrokeMessage(strokeId: id, phase: .begin, color: .gold, baseWidth: 4, points: [p])
        document.apply(m, isRemote: false, now: CACurrentMediaTime())
        canvas?.update(document.strokes.last!)
        onOutgoing?(.stroke(m))
        return id
    }
    func appendLocal(_ id: UInt32, _ points: [StrokePoint]) {
        let m = StrokeMessage(strokeId: id, phase: .append, color: .gold, baseWidth: 4, points: points)
        document.apply(m, isRemote: false, now: CACurrentMediaTime())
        if let s = document.strokes.first(where: { $0.id == id }) { canvas?.update(s) }
        onOutgoing?(.stroke(m))
    }
    func endLocal(_ id: UInt32) {
        let m = StrokeMessage(strokeId: id, phase: .end, color: .gold, baseWidth: 4, points: [])
        document.apply(m, isRemote: false, now: CACurrentMediaTime())
        onOutgoing?(.stroke(m))
    }
    func cursorMoved(_ c: Cursor) { onOutgoing?(.cursor(c)) }

    // Remote input (wired in Task 13)
    public func applyRemote(_ m: StrokeMessage) {
        document.apply(m, isRemote: true, now: CACurrentMediaTime())
        if let s = document.strokes.first(where: { $0.id == m.strokeId }) { canvas?.update(s) }
    }
    public func undoRemote(id: UInt32) { document.remove(id: id); canvas?.remove(id: id, duration: 0.15) }
    public func clearRemote() { document.clear(); canvas?.removeAll() }
    public func remoteCursor(_ c: Cursor, name: String) { canvas?.showRemoteCursor(c, name: name) }

    // Commands
    public func undoLocal() {
        guard let id = document.undoLastLocal() else { return }
        canvas?.remove(id: id, duration: 0.15)
        onOutgoing?(.undo(strokeId: id))
    }
    public func clearLocal() { document.clear(); canvas?.removeAll(); onOutgoing?(.clear) }

    /// Called 30 times a second by the canvas: starts fades and drops finished strokes.
    func tick() {
        let now = CACurrentMediaTime()
        for s in document.strokes where s.endedAt != nil && document.opacity(of: s, now: now) < 1 { canvas?.fade(id: s.id, duration: document.fadeDuration) }

    // Rendering
    func update(_ stroke: Stroke) {
        let shape = layers[stroke.id] ?? makeLayer(for: stroke)
        shape.path = ribbon(for: stroke)
    }

    private func makeLayer(for stroke: Stroke) -> CAShapeLayer {
        let l = CAShapeLayer()
        let color = stroke.isRemote ? NSColor(srgbRed: 243 / 255, green: 227 / 255, blue: 186 / 255, alpha: 1) : NSColor(srgbRed: 201 / 255, green: 168 / 255, blue: 106 / 255, alpha: 1)
        l.fillColor = color.cgColor; l.strokeColor = color.cgColor; l.lineWidth = 1; l.lineJoin = .round; l.lineCap = .round
        l.contentsScale = window?.backingScaleFactor ?? 2
        layer?.insertSublayer(l, below: cursorDot)
        layers[stroke.id] = l
        return l
    }

    /// Variable-width ribbon: the smoothed centerline offset by half the per-point width on each side.
    private func ribbon(for stroke: Stroke) -> CGPath {
        let path = CGMutablePath()
        let w = bounds.width, h = bounds.height
        let pts = stroke.points
        guard let first = pts.first else { return path }
        if pts.count == 1 {
            let r = CGFloat(stroke.baseWidth) * 0.6
            path.addEllipse(in: CGRect(x: CGFloat(first.x) * w - r, y: CGFloat(first.y) * h - r, width: 2 * r, height: 2 * r))
            return path
        }
        var widths: [CGFloat] = []
        var smoothed: Float = stroke.baseWidth
        for i in 0..<pts.count {
            let speed = i == 0 ? 0 : InkGeometry.speed(from: pts[i - 1], to: pts[i])
            let target = InkGeometry.width(base: stroke.baseWidth * pts[i].pressure, speedPerMs: speed)
            smoothed += (target - smoothed) * 0.3
            widths.append(CGFloat(smoothed))
        }
        let center = InkGeometry.smooth(pts, segments: 6).map { CGPoint(x: CGFloat($0.x) * w, y: CGFloat($0.y) * h) }
        guard center.count > 1 else { return path }
        var left: [CGPoint] = [], right: [CGPoint] = []
        for i in 0..<center.count {
            let a = center[max(0, i - 1)], b = center[min(center.count - 1, i + 1)]
            var nx = -(b.y - a.y), ny = b.x - a.x
            let len = max(hypot(nx, ny), 0.0001); nx /= len; ny /= len
            let half = widths[min(widths.count - 1, i * (widths.count - 1) / max(1, center.count - 1))] / 2
            left.append(CGPoint(x: center[i].x + nx * half, y: center[i].y + ny * half))
            right.append(CGPoint(x: center[i].x - nx * half, y: center[i].y - ny * half))
        }
        path.move(to: left[0]); left.dropFirst().forEach { path.addLine(to: $0) }
        right.reversed().forEach { path.addLine(to: $0) }
        path.closeSubpath()
        return path
    }

    func fade(id: UInt32, duration: Double) {
        guard !fading.contains(id), let l = layers[id] else { return }
        fading.insert(id)
        animateOpacity(l, to: 0, duration: duration) { [weak self] in self?.layers[id]?.removeFromSuperlayer(); self?.layers[id] = nil; self?.fading.remove(id) }
    }
    func remove(id: UInt32, duration: Double) { fade(id: id, duration: duration) }
    func removeAll() { layers.keys.forEach { remove(id: $0, duration: 0.15) } }

    private func animateOpacity(_ l: CALayer, to value: Float, duration: Double, completion: @escaping () -> Void) {
        let reduce = NSWorkspace.shared.accessibilityDisplayShouldReduceMotion
        CATransaction.begin()
        CATransaction.setCompletionBlock(completion)
        let a = CABasicAnimation(keyPath: "opacity")
        a.fromValue = l.presentation()?.opacity ?? l.opacity; a.toValue = value
        a.duration = reduce ? duration * 0.5 : duration
        a.timingFunction = CAMediaTimingFunction(controlPoints: 0.23, 1, 0.32, 1)
        l.opacity = value
        l.add(a, forKey: "opacity")
        CATransaction.commit()
    }

    func showRemoteCursor(_ c: Cursor, name: String) {
        CATransaction.begin(); CATransaction.setDisableActions(true)
        cursorDot.position = CGPoint(x: CGFloat(c.x) * bounds.width, y: CGFloat(c.y) * bounds.height)
        cursorLabel.string = name

        CATransaction.commit()
        let target: Float = c.visible ? 1 : 0
        if cursorDot.opacity != target { cursorDot.opacity = target; cursorLabel.opacity = target }
    }
}
```

```swift
import Foundation

public enum LinkTLS {
    /// TCP with no delay and TLS 1.2 ECDHE_PSK (spec section 13: the ephemeral ECDH part stops offline guessing of the code from a recorded handshake).
    public static func parameters(code: String, sharerName: String) -> NWParameters {
        let tls = NWProtocolTLS.Options()
        let options = tls.securityProtocolOptions
        let key = Pairing.presharedKey(code: code, sharerName: sharerName)
        let psk = key.withUnsafeBytes { DispatchData(bytes: $0) }
        let identity = Data(Pairing.pskIdentity.utf8).withUnsafeBytes { DispatchData(bytes: $0) }
        sec_protocol_options_add_pre_shared_key(options, psk as __DispatchData, identity as __DispatchData)
        sec_protocol_options_append_tls_ciphersuite(options, tls_ciphersuite_t(rawValue: UInt16(TLS_ECDHE_PSK_WITH_CHACHA20_POLY1305_SHA256))!)
        sec_protocol_options_set_min_tls_protocol_version(options, .TLSv12)
        sec_protocol_options_set_max_tls_protocol_version(options, .TLSv12)

        let tcp = NWProtocolTCP.Options()
        tcp.noDelay = true
        tcp.connectionTimeout = 5
        let params = NWParameters(tls: tls, tcp: tcp)
        params.includePeerToPeer = true
        return params
    }
}
```

```swift
import Foundation
import Network
import QuartzCore
import NitidoCore
import os

private let log = Logger(subsystem: "ai.ronar.nitido", category: "link")

/// One encrypted connection. Frames messages, answers pings, measures RTT and clock offset, tracks send backlog.
public final class Link: @unchecked Sendable {
    public enum State: Sendable, Equatable { case connecting, ready, failed(String), cancelled }

    public let role: Role
    public let messages: AsyncStream<Message>
    public let states: AsyncStream<State>
    public private(set) var state: State = .connecting
    public private(set) var peerHello: Hello?
    public private(set) var lastRTTMs: Double?
    /// Peer clock minus local clock, nanoseconds, estimated from ping/pong (nil until the first pong).
    public private(set) var clockOffsetNs: Int64?
    public var backlogBytes: Int { lock.lock(); defer { lock.unlock() }; return backlog }

    private let connection: NWConnection
    private let hello: Hello
    private let queue = DispatchQueue(label: "ai.ronar.nitido.link", qos: .userInteractive)
    private let lock = NSLock()
    private var backlog = 0
    private var decoder = Wire.Decoder()
    private var pingTimer: DispatchSourceTimer?
    private var nextPing: UInt32 = 0
    private var pingSentAt: [UInt32: Double] = [:]
    private let messageOut: AsyncStream<Message>.Continuation
    private let stateOut: AsyncStream<State>.Continuation

    init(connection: NWConnection, role: Role, hello: Hello) {
        self.connection = connection; self.role = role; self.hello = hello
        (messages, messageOut) = AsyncStream.makeStream(bufferingPolicy: .unbounded)
        (states, stateOut) = AsyncStream.makeStream(bufferingPolicy: .bufferingNewest(16))
    }

    public static func connect(to endpoint: NWEndpoint, code: String, sharerName: String, hello: Hello) -> Link {
        let link = Link(connection: NWConnection(to: endpoint, using: LinkTLS.parameters(code: code, sharerName: sharerName)), role: .view, hello: hello)
        link.start()
        return link
    }

    func start() {
        connection.stateUpdateHandler = { [weak self] s in
            guard let self else { return }
            switch s {
            case .ready:
                setState(.ready); send(.hello(hello)); receiveLoop(); startPings()
            case .failed(let e): finish(.failed(e.localizedDescription))
            case .cancelled: finish(.cancelled)
            case .waiting(let e): log.info("waiting: \(e.localizedDescription)")
            default: break
            }
        }
        connection.start(queue: queue)
    }

    public func send(_ m: Message) {
        let data = Wire.encode(m)
        lock.lock(); backlog += data.count; lock.unlock()
        connection.send(content: data, completion: .contentProcessed { [weak self] error in
            guard let self else { return }
            lock.lock(); backlog -= data.count; lock.unlock()
            if let error { log.error("send: \(error.localizedDescription)") }
        })
    }

    public func close() {
        pingTimer?.cancel(); pingTimer = nil
        connection.send(content: Wire.encode(.bye(reason: 0)), completion: .contentProcessed { [weak self] _ in self?.connection.cancel() })
    }

    private func receiveLoop() {
        connection.receive(minimumIncompleteLength: 1, maximumLength: 1 << 20) { [weak self] data, _, complete, error in
            guard let self else { return }
            if let data, !data.isEmpty {
                do { for m in try decoder.feed(data) { handle(m) } }
                catch { finish(.failed("protocol: \(error)")); connection.cancel(); return }
            }
            if let error { finish(.failed(error.localizedDescription)); return }
            if complete { finish(.cancelled); return }
            receiveLoop()
        }
    }

    private func handle(_ m: Message) {
        let now = CACurrentMediaTime()
        switch m {
        case .hello(let h):
            peerHello = h
            if h.protocolVersion != protocolVersion { send(.bye(reason: 1)); finish(.failed("protocol version \(h.protocolVersion), expected \(protocolVersion)")); connection.cancel(); return }
            messageOut.yield(m)
        case .ping(let id, let t):
            send(.pong(id: id, originalTNs: t, replyTNs: UInt64(now * 1e9)))
        case .pong(let id, let original, let reply):
            lock.lock(); let sent = pingSentAt.removeValue(forKey: id); lock.unlock()
            guard sent != nil else { return }
            let t0 = Double(original) / 1e9, t3 = now
            lastRTTMs = (t3 - t0) * 1000
            clockOffsetNs = Int64(reply) - Int64(((t0 + t3) / 2) * 1e9)
        case .bye:
            finish(.cancelled); connection.cancel()
        default:
            messageOut.yield(m)
        }
    }

    private func startPings() {
        let timer = DispatchSource.makeTimerSource(queue: queue)
        timer.schedule(deadline: .now() + 0.1, repeating: 0.5)
        timer.setEventHandler { [weak self] in
            guard let self else { return }
            lock.lock(); nextPing &+= 1; let id = nextPing; pingSentAt[id] = CACurrentMediaTime(); pingSentAt = pingSentAt.filter { CACurrentMediaTime() - $0.value < 10 }; lock.unlock()
            send(.ping(id: id, tNs: UInt64(CACurrentMediaTime() * 1e9)))
        }
        timer.resume()
        pingTimer = timer
    }

    private func setState(_ s: State) { state = s; stateOut.yield(s) }

    private func finish(_ s: State) {
        guard state == .ready || state == .connecting else { return }
        pingTimer?.cancel(); pingTimer = nil
        setState(s)
        messageOut.finish(); stateOut.finish()
    }
}
```

```swift
        }
    }
```

```swift
import Foundation
import Network
import NitidoCore
import os

private let log = Logger(subsystem: "ai.ronar.nitido", category: "session")

/// A viewer-side connection that survives drops: reconnects with backoff (0.5, 1, 2, 5 s) while open.
/// A failure before the first ready state is treated as a bad code and ends the session.
public final class LinkSession: @unchecked Sendable {
    public enum State: Sendable, Equatable {
        case connecting(attempt: Int)
        case ready
        case reconnecting(attempt: Int, delay: Double)
        case closed(String?)
    }

    public let messages: AsyncStream<Message>
    public let states: AsyncStream<State>
    public var lastRTTMs: Double? { current?.lastRTTMs }
    public var clockOffsetNs: Int64? { current?.clockOffsetNs }
    public var backlogBytes: Int { current?.backlogBytes ?? 0 }

    private let endpoint: NWEndpoint, code: String, sharerName: String, hello: Hello
    private let lock = NSLock()
    private var _current: Link?
    private var current: Link? { lock.lock(); defer { lock.unlock() }; return _current }
    private var open = true
    private var attempt = 0
    private var everReady = false
    private let messageOut: AsyncStream<Message>.Continuation
    private let stateOut: AsyncStream<State>.Continuation

    public init(endpoint: NWEndpoint, code: String, sharerName: String, hello: Hello) {
        self.endpoint = endpoint; self.code = code; self.sharerName = sharerName; self.hello = hello
        (messages, messageOut) = AsyncStream.makeStream(bufferingPolicy: .unbounded)
        (states, stateOut) = AsyncStream.makeStream(bufferingPolicy: .bufferingNewest(16))
    }

    public func start() { attemptConnection() }
    public func send(_ m: Message) { current?.send(m) }

    public func close() {
        lock.lock(); open = false; let link = _current; lock.unlock()
        link?.close()
        stateOut.yield(.closed(nil)); stateOut.finish(); messageOut.finish()
    }

    private func attemptConnection() {
        lock.lock()
        guard open else { lock.unlock(); return }
        attempt += 1
        let n = attempt
        let link = Link.connect(to: endpoint, code: code, sharerName: sharerName, hello: hello)
        _current = link
        lock.unlock()
        stateOut.yield(.connecting(attempt: n))
        Task { [weak self] in
            guard let self else { return }
            for await m in link.messages { messageOut.yield(m) }
        }
        Task { [weak self] in
            guard let self else { return }
            for await s in link.states {
                switch s {
                case .ready:
                    lock.lock(); everReady = true; attempt = 0; lock.unlock()
                    stateOut.yield(.ready)
                case .failed(let reason):
                    scheduleRetry(after: reason)
                case .cancelled:
                    lock.lock(); let stillOpen = open; lock.unlock()
                    if stillOpen { end("The sharer ended the session.") }
                case .connecting: break
                }
            }
        }
    }

    private func scheduleRetry(after reason: String) {
        lock.lock(); let stillOpen = open, ready = everReady, n = attempt; lock.unlock()
        guard stillOpen else { return }
        guard ready else { end("Could not connect. Check the code and try again."); return }
        let delay = min(5, 0.5 * pow(2, Double(max(0, n - 1))))
        log.info("link failed (\(reason)); retry \(n) in \(delay)s")
        stateOut.yield(.reconnecting(attempt: n, delay: delay))
        Task { [weak self] in
            try? await Task.sleep(for: .milliseconds(Int(delay * 1000)))
            self?.attemptConnection()
        }
    }

    private func end(_ reason: String) {
        lock.lock(); open = false; lock.unlock()
        stateOut.yield(.closed(reason)); stateOut.finish(); messageOut.finish()
    }
}
```
The retry counter must count consecutive failures, so `attempt` resets to 0 on `.ready` and the first retry after a drop is attempt 1 with a 0.5 s delay, as the test expects.

```markdown
## How it works

`NitidoCore` is pure Swift and fully unit-tested: the wire protocol (big-endian, length-prefixed, 11 message types), rolling telemetry with p50/p95, a deterministic bitrate controller, ink geometry and the HKDF pairing key. `NitidoCapture` wraps ScreenCaptureKit, `NitidoCodec` wraps VideoToolbox in realtime mode with no frame reordering, `NitidoLink` wraps Network.framework with Bonjour discovery and TLS-PSK, and `NitidoUI` renders through a `CAMetalLayer` with Core Image so pixels map 1:1. Nothing ever grows a queue: the encoder takes only the newest frame, the sender skips non-key frames when the backlog passes four frames, and the viewer shows only the newest decoded frame. The design spec and the implementation plan are in `docs/superpowers/`.

## Run it

Requires macOS 15 or later and Xcode 26. `scripts/fetch-fonts.sh && scripts/bundle.sh && open build/Nítido.app`, or `swift run nitido` for a quick look. macOS asks for Screen Recording the first time. To try the network path on one Mac, launch the app twice (`open -n build/Nítido.app`).

## Security

Pairing uses TLS 1.2 with a pre-shared key derived from the 4-digit code, over an ECDHE_PSK ciphersuite, so someone who only records the network traffic cannot decrypt the session, not even later. The code has only 10,000 values, though: an active attacker on the same network can pose as the sharer and guess the code during the handshake in real time. Use Nítido on a network you trust (home, office), not on public Wi-Fi. A PAKE such as SPAKE2, or a 128-bit secret shared by QR code, is the next step; the details are in section 13 of the design spec.

## What's next

WebRTC with STUN/TURN for the open internet, AV1 where hardware allows, a region-diff pass so static text costs no bits, and audio.
```
